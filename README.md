A trend bot racing Coinbase Wrapped BTC (cbBTC) vs USDC on 1-minute bars with $1,000 of paper money. It enters only on a confirmed uptrend — 15-bar return above 20 bps, close above EMA(48), EMA(12) above EMA(48) — and exits on a 2% trailing stop or a 10% equity drawdown guard. It trades rarely on purpose: a full-size round trip costs ~46 bps in fees, slippage, and pool impact, so 1-minute noise is untradable and every exit has to clear that bar. Fully deterministic, no network, no wall clock.

## Run it

```sh
node main.ts
```
